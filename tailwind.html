Web technologies and tools

Essential things for your web development toolbox

An opinionated list...

HTML5

The standard markup language for creating web pages.

CSS3

Style your web pages with modern layouts and animations.

JavaScript

Add interactivity and dynamic content to your sites, and use JavaScript based build tools.

Node.js

Run JavaScript on the server for scalable web apps and locally for building sites.

Tailwind CSS

A utility-first CSS framework for rapid UI development.

Vue.js

A progressive JavaScript framework for building user interfaces.

Git and GitHub

Version control system for tracking code changes.

VS Code

Visual Studio Code provides developers with a new choice of tool that combines the simplicity of a code editor with the best tooling for their core edit-build-debug cycle.

Astro

Astro is a JavaScript web framework optimized for building fast, content-driven websites.
